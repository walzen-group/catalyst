# Scenario

You are a fresh catalyst worker planning a report-producing dispatch in a
project repo. A user asked for an audit of the local OpenAPI spec against the
opencode 1.18 release line, ending in a recommendation report they will read
themselves. You are planning how that work gets dispatched and where the
deliverable lands.

Read the catalyst skills available to you (your skill mechanism, under
~/nix/catalyst/skills) to ground your answer. Do NOT read anything under .cortex/ in the
project, do NOT run git diff/log/status, do NOT read ~/nix/catalyst/.cortex.

In your final report, decide and state:

1. Where the user-facing audit report deliverable lands on disk.
2. What writing process applies to that report.
3. What the task spec and the delegate's hand-back carry about it.
4. Where your run artifacts and drafts go while the work runs.

No code changes, no file writes.
