# Catalyst integration tests

## What this is

The catalyst integration-test suite. One directory per guarded rule, with the shared runner in
lib/runner.mjs. Tests run on a manual trigger, no CI. The practice is the
catalyst-v2-self-testing skill; every live launch goes through the c2d CLI.

## How to run

- `node lib/runner.mjs run <rule-slug>`: a live run, launches the actor and judge through c2d.
- `node lib/runner.mjs new <slug>`: scaffolds a new test directory.
- `cd .cortex/.tests/catalyst && node --test`: the runner's own unit suite.

## Keeping the index current

The runner rewrites the row's last-result cell after each run; the row format is pinned in the
runner. Full per-run detail, verdicts, judge reasoning, and models used, lives in each test's
history/. Each run's -log.md holds the raw LLM output, the verbatim actor transcript and judge
report, for exact-output checks and cross-run comparison.
